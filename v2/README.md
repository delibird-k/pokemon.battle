# ポケモンバトルシミュレーター v2

このディレクトリは、既存版を壊さずに新しい設計へ移行するための独立した実装です。

## 設計方針

- **画面(UI)・ゲームルール(core)・CPU(ai)・通信(online)・保存(storage)を分離する。**
- ルール層はDOM、通信、ブラウザ保存機能に依存しない。
- バトル状態は1つのStateとして扱い、変更はReducer経由に限定する。
- 画面はStateを表示するだけにし、画面側でダメージ計算をしない。
- 既存版の機能を確認しながら移植し、機能を黙って削らない。

## ディレクトリ

- `src/data/`: ポケモン・技・持ち物などのデータ
- `src/core/`: バトル状態、タイプ相性、ダメージ、ターン処理
- `src/ai/`: CPUの判断
- `src/online/`: 対人通信
- `src/storage/`: 設定・履歴・レートの保存
- `src/ui/`: 画面描画と操作
- `tests/`: ルール層の自動テスト

## 現在の移行段階

1. 独立したv2の土台とルール層を作成。
2. 既存版のポケモン・技・持ち物データを移植。
3. 3対3の対戦進行、交代、状態異常、特性・持ち物を移植。
4. CPUを移植し、旧版と同条件で対戦結果を比較。
5. オンライン対戦を移植し、2端末で同期を検証。
6. カスタマイズ、テラスタル、ダイマックス、履歴・レートを移植。
7. 旧版と同等の機能確認後に公開版へ切り替え。

**注意:** v2は移行中です。現行の `index.html` と `ai.js` はこの段階では変更しません。v2が未完成のまま公開版を置き換えることはありません。
