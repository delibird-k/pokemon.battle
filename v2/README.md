# ポケモンバトルシミュレーター v2

このディレクトリは、現行版を維持しながら段階的に置き換えるための独立実装です。未完成のv2を現行公開版に上書きしません。

## 設計方針

- UI・ゲームルール・CPU・通信・保存を分離する。
- ルール層はDOM、通信、ブラウザ保存機能に依存しない。
- バトル状態はStateとして扱い、変更はReducer経由に限定する。
- 画面側でダメージ計算や通信パケットの解釈を重複実装しない。
- 既存版の機能を確認しながら移植し、機能を黙って削らない。

## ディレクトリ

- `src/data/`: ポケモン・技・持ち物データ
- `src/core/`: バトル状態、タイプ相性、ダメージ、ターン処理
- `src/ai/`: CPUの判断
- `src/online/`: 対人通信と通信プロトコル
- `src/storage/`: 設定・履歴・レートの保存
- `src/ui/`: 画面描画と操作
- `tests/`: ルール・保存・通信プロトコルのテスト

## 現行版について

現行版の主な実装は `index.html` と `ai.js` にあります。現行版にはPeerJSによるオンライン接続、localStorageによる戦績・設定保存、IndexedDBによるAPIデータキャッシュがあります。これらを削除するのではなく、仕様を確認してv2へ移します。

## テスト

`npm test` でNode.js標準テストランナーを実行します。テストコードを追加した段階であり、実行環境での成功を確認できていない場合は「テスト合格」と扱いません。
